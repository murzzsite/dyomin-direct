# Павел Демин: лендинг (Яндекс Директ, карты, сайты)

Чистый HTML/CSS/JS, без сборки. Заявки идут через Cloudflare Worker в Telegram (ref `TTX55BZ3XZ`, endpoint в первой строке `script.js`).

## Идея
«Директ от заявки»: бренд Backward Digital = считаем назад. Живой калькулятор переводит нужное число клиентов в заявки и рекламный бюджет.

## Шрифты и палитра
Fira Sans Extra Condensed 800 (заголовки, с кириллицей) + EB Garamond (текст). Поле carmine #d4202f, бумага #f4f4f2, ink #15171a.
